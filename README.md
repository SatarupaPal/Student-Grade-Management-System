# Student Grade Management System 🎓

A console-based Student Grade Management System built using Python to manage student academic records. This project implements CRUD (Create, Read, Update, Delete) operations and uses JSON for data persistence.

## 🚀 Key Features

- **Student Registration:** Add student records with roll numbers, names, subject names, and marks.
- **Automated Grade Calculation:** Calculate total marks, average, letter grade, and pass/fail status automatically.
- **View Records:** Display all stored student records with their academic details.
- **Search Student:** Find student records using their roll number.
- **Update Records:** Update student names or subject marks.
- **Delete Records:** Remove student records with a confirmation step.
- **Input Validation:** Validate user inputs and prevent duplicate roll numbers.
- **Persistent Storage:** Store student records in a JSON file to retain data between application runs.

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Data Storage:** JSON (JavaScript Object Notation)

## 💻 How to Run Locally

1. **Clone this repository:**

   ```bash
   git clone https://github.com/SatarupaPal/Student-Grade-Management-System.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd Student-Grade-Management-System
   ```

3. **Run the Python file:**

   ```bash
   python main.py
   ```
